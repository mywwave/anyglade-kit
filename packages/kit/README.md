# @anyglade/kit

React UI kit на HeroUI v3: все компоненты HeroUI, своя тема и собственные компоненты из одного пакета.

Требования: React 19+, Tailwind CSS 4+.

## Установка

```bash
bun add @anyglade/kit
```

HeroUI и React Aria ставятся вместе с пакетом. Отдельный Provider не нужен.

## Для ИИ-агентов

Правила дизайн-системы лежат в пакете и обновляются вместе с ним. При установке агенты подключаются сами: Claude Code и Codex через скилл, Cursor и остальные через `AGENTS.md`. В проект ложатся только ссылки.

Bun и pnpm не запускают скрипты зависимостей без разрешения, поэтому там установите с доверием или подключите одной командой:

```bash
bun add --trust @anyglade/kit
bunx @anyglade/kit init
```

Отключить автоматическое подключение можно переменной `ANYGLADE_KIT_NO_AGENTS=1`.

## Подключение

В главном CSS-файле приложения, строго в таком порядке:

```css
@import "tailwindcss";
@import "@anyglade/kit/styles.css";
```

Использование:

```tsx
import { Button, PageHeader } from "@anyglade/kit";

export function Page() {
  return <PageHeader title="Orders" actions={<Button>Create</Button>} />;
}
```

Импортируйте компоненты только из `@anyglade/kit`, а не из `@heroui/react`, иначе обёртки и замены kit не применятся.

## Вёрстка

`Box` и `Text` принимают только токены. `className` и `style` закрыты на уровне типов, а тёмная тема работает без `dark:`.

```tsx
import { Box, Text } from "@anyglade/kit";

export function Card() {
  return (
    <Box
      flexDirection="column"
      gap="m"
      padding={{ base: "l", md: "xl" }}
      backgroundColor={{ base: "background-card", hover: "background-secondary" }}
      borderRadius="l"
    >
      <Text as="h3" variant="heading-xs">
        Revenue
      </Text>
      <Text variant="body" tabularNums formatter="number">
        {3290033}
      </Text>
    </Box>
  );
}
```

`Box` по умолчанию `display: flex`, кроме `span`, `label`, `li` и `a`. Элемент меняется через `as`. Значения токенов доступны в JavaScript через `tokens`. Ширину содержимого задают `tokens.widths`: `form`, `content`, `wide`.

## Паттерны

Готовые композиции поверх `Box` и `Text`:

- `Frame` и `FrameTile` — рамка с заголовком и плитками внутри.
- `Stat` — подпись и значение с табличными цифрами.
- `DetailRow` — строка подпись и значение, пустое значение показывается как «—».
- `EmptyPanel` — пустое состояние с иконкой и действиями.
- `CopyButton` — копирование с подтверждением прямо на кнопке.
- `SegmentedControl` — фильтр из нескольких вариантов с перетекающим индикатором.
- `SortableColumn` и `useTableSort` — сортировка таблицы по значениям, а не по подписям.
- `Loadable` — скелетон на время загрузки и плавное появление контента.
- `TreeNav` — боковая панель в виде дерева: группы раскрываются, выбранный пункт отмечен, справа статус.
- `CountBadge` — счётчик нового: непрочитанное, очередь. Больше 99 показывает «99+», при росте числа коротко вздрагивает.
- `PageLoader` — запуск приложения: логотип с медленным бликом, тонкая полоса и строка состояния на весь экран. Появляется, только если работа длится дольше `delay`, по умолчанию 400 мс, поэтому быстрые страницы открываются без него.
- `TextSwap` — короткий текст, сменивший состояние: двигается только изменившаяся часть, а ширина плавная. С `isShimmering` строка меняется целиком. Одна строка на действие: таймеры, значения за вводом, таблицы и предложения идут без него.
- `MediaStage`, `MediaTile`, `StreamVideo` — сцена звонка: сетка или один на сцене с лентой остальных, плитка с подписью и кольцом говорящего, живой поток.
- `Draggable` — перенос значения на строки `ItemList` с пропом `drop`. Дублируйте действие в меню для касания и клавиатуры.
- `FloatingPanel` — поповер у кнопки, который можно закрепить на экране и перетащить. Без `triggerRef` стоит сам по себе, таких окон может быть много, клик поднимает окно наверх. `resize` добавляет изменение размера. Страница под ним работает. Потянули за заголовок, и он закрепился сам. Клавиатура: стрелки на заголовке.
- `Masonry` и `MasonryTile` — галерея плиток разной высоты: колонки заполняются сверху вниз, живой объект стоит на спокойной сцене, подпись под ним. Одна колонка на телефоне, две от `md`, три от `lg`.
- `SlideToConfirm` — подтверждение жестом для действия, которое нельзя совершить случайно: перевод денег, удаление. Бегунок тянется до конца, заливка идёт за ним, `onConfirm` с промисом держит лоадер, ошибка возвращает бегунок. С клавиатуры Enter.
- `SignaturePad` — подпись от руки. Чернила берут цвет текста, `onChange` отдаёт PNG data URL после каждого штриха и `null` после очистки.
- `ItemList` — строки, которые открывают объект и несут свои кнопки: чаты, письма, задачи. Стрелки ходят по строкам, Enter открывает, стрелка вправо ведёт к кнопкам строки. Опция `menu` добавляет контекстное меню: правая кнопка, долгое нажатие, клавиша меню.

## Загрузка и движение

Лоадер у кнопки появляется сам. Есть три способа, ни один не требует разметки:

```tsx
<Button onPress={save}>Сохранить</Button> // onPress вернул промис

<form action={save}>
  <Button type="submit">Сохранить</Button> // форма отправляется
</form>

<Button isPending={isSaving}>Сохранить</Button> // состояние снаружи
```

`action` подходит для форм без контролируемых полей. React сбрасывает форму после `action`, и `TextField` из React Aria откатывает значение к начальному. Для контролируемых полей используйте `onSubmit` с `useTransition` и передавайте `isPending`.

Кнопка сразу перестаёт нажиматься, а лоадер показывается через 150 мс и держится минимум 400 мс. Ширина не меняется. Те же правила для своих индикаторов даёт `useLoadingIndicator(isLoading)`.

Для перетекания оберните изменение состояния в `withTransition`, а элементу задайте `viewTransitionName`. Пока открыт `FloatingPanel`, снимок страницы не делается. Строки `ItemList` переезжают сами, без снимка. Появление отдельного элемента задаёт `<Box motion="fade | enter | pop">`.

```ts
lint: {
  jsPlugins: [{ name: "anyglade", specifier: "@anyglade/kit/oxlint" }],
  rules: {
    "anyglade/no-raw-layout": "error",
    "anyglade/no-raw-text": "error",
    "anyglade/no-typography-utility": "error",
    "anyglade/no-spacing-utility": "error",
    "anyglade/no-foreign-import": "error",
    "anyglade/no-dark-variant": "error",
    "anyglade/no-arbitrary-value": "error",
  },
},
```

Типографика и отступы задаются только через `Text` и `Box`. Утилиты Tailwind вроде `text-sm` или `font-semibold` и компоненты HeroUI берут значения из той же шкалы, поэтому система остаётся единой и без линта.

## Акцент

Акцент отвечает на два вопроса: что здесь главное действие и что сейчас включено. Всё остальное остаётся монохромным. Без заданного цвета акцентом служит основной цвет текста, и это полноценная тема.

- **Одна основная кнопка на экран или блок.** `variant="primary"` получает действие, ради которого человек пришёл. Остальные кнопки `secondary` или `ghost`. Если главного действия нет, основной кнопки тоже нет. `primary` стоит по умолчанию, поэтому вариант у второстепенной кнопки указывается всегда.
- **Включённое состояние контрола.** Чекбокс, радио, переключатель и ползунок красятся акцентом сами. Выбор в навигации, фильтрах и таблицах остаётся нейтральным, как в `SegmentedControl`.
- **Текст акцентом только у ссылок.** Заголовки, числа, суммы, подписи и иконки акцентом не красятся. Важность задают размер, вес и формулировка.
- **Никаких заливок поверхностей и рамок.** Акцент не красит секции, карточки и фоны. Сильный участок экрана делается через `background-inverse`. Заливки акцентом занимают меньше 10 % площади блока.
- **Статус не акцент.** Успех, предупреждение и ошибка имеют свои цвета, удаление идёт через `danger`. Акцент не должен читаться как статус: тон `success`, янтарный, красный и насыщенный оранжевый между ними не подходят. Мята и приглушённая глина подходят: они мягче статусов и не совпадают с ними по тону.
- **Спокойный цвет.** Акцент не бывает кислотным. Готовые цвета панели имеют одну светлоту и насыщенность в OKLCH (0,74 и 0,1), по одному на семейство тонов. Свой цвет бренда берите близким к этой насыщенности.
- **Одна серия на график.** Акцент получает главная серия, остальные нейтральные. Спарклайны нейтральные всегда.
- **Контраст обязателен.** Подпись на акценте и текст акцентом держат 4,5, контролы без подписи на заливке, линии графика и фокус держат 3 на всех поверхностях. Кнопка сохраняет точный цвет бренда: её читаемость держит подпись. Цвет подписи выбирается по большему контрасту. Текст и линии задаются парой значений для светлой и тёмной темы. Панель «Тема» выводит такую пару из одного цвета бренда и сдвигает его только там, где не хватает контраста. Тон контролов лежит в `--ag-accent-control`.
- **Цвет не единственный сигнал.** Включённое состояние видно и без цвета: по галочке, положению, форме.

Витрина компонентов показывает варианты и под правило одной кнопки не попадает. Последний аудит лежит в `docs/design-system/accent-audit.md`.

## AI

Компоненты интерфейса с агентом лежат в отдельном входе `@anyglade/kit/ai`, чтобы не утяжелять проекты без него. Они не зависят от провайдера и принимают обычные данные, поэтому подходят для любого SDK. Подписи передаются пропсами.

| Компонент                       | Что покрывает                                                                             |
| ------------------------------- | ----------------------------------------------------------------------------------------- |
| `Conversation`                  | Лента на скролле страницы, вопрос наверху, ответ растёт под ним                           |
| `Message`, `StreamingText`      | Реплика и ответ по словам. Метка `[1]` становится ссылкой на источник                     |
| `DeliveryStatus`                | Галочки своего сообщения, слово в подсказке. Слот `meta` у `Message`                      |
| `PromptComposer`, `Suggestions` | Ввод, вложения, отправка и остановка в одном месте, подсказки                             |
| `Reasoning`                     | Рассуждения агента                                                                        |
| `Plan`                          | Что агент собирается сделать: отдельный объект с заголовком, прогрессом и шагами на линии |
| `Run`                           | План, очередь, задачи, цепочка шагов, прогон тестов. Шаги субагента идут в `steps`        |
| `ToolCall`                      | Вызов инструмента и подтверждение перед ним                                               |
| `CodeOutput`                    | Вывод терминала и трассировка стека                                                       |
| `FileTree`                      | Изменённые файлы                                                                          |
| `Sources`, `Citation`           | Источники списком и в тексте                                                              |
| `ModelPicker`, `ContextMeter`   | Модель, глубина, заполнение контекста                                                     |
| `Checkpoint`                    | Точка, к которой можно вернуться                                                          |

Скроллится страница. Новый вопрос уезжает наверх, а ответ растёт в свободное место под ним. Когда он доходит до поля ввода, страница плавно едет за ним, а если читатель прокрутил вверх, остаётся на месте и показывает кнопку вниз. Каждую реплику оборачивайте в `ConversationTurn`, в `followKey` передавайте id последней реплики, а в `topInset` высоту всего, что прилипло сверху.

Блоки появляются через `opacity` и `transform`, поэтому раскладка не пересчитывается на каждом кадре. Держите состояние стрима отдельно от поля ввода и мемоизируйте реплики: новое слово должно перерисовывать только свой абзац. Строки шагов держат постоянную высоту.

`Shimmer` лежит в основном входе и принимает строку. Он означает только «идёт работа». Блик это отдельный слой поверх текста. После остановки он доходит до конца прохода и снимается, когда уже вне текста, поэтому буквы не перерисовываются и окончания не видно. При `prefers-reduced-motion` остаётся обычный текст.

## Графики

Графики подключаются отдельным входом, поэтому проекты без них не получают Recharts в бандл:

```tsx
import { LineChart } from "@anyglade/kit/charts";

export function Revenue() {
  return (
    <LineChart
      label="Выручка по месяцам"
      data={[{ month: "Окт", revenue: 120 }]}
      xKey="month"
      series={[{ dataKey: "revenue", label: "Выручка" }]}
    />
  );
}
```

Доступны `LineChart`, `AreaChart`, `BarChart`, `DonutChart` и `Sparkline`. Цвета берутся из токенов, серий не больше трёх.

## Иконки

Набор [Gravity UI Icons](https://gravity-ui.com/icons) подключается отдельным входом, потому что часть имён совпадает с компонентами (`Link`, `Calendar`, `Tag`):

```tsx
import { Button } from "@anyglade/kit";
import { Persons } from "@anyglade/kit/icons";

export function Invite() {
  return (
    <Button>
      <Persons />
      Invite
    </Button>
  );
}
```

В бандл попадают только используемые иконки. Иконка `Box` совпадает с компонентом, поэтому импортируйте её как `Box as BoxIcon`.

## Шрифт

Inter подключён вместе со стилями и раздаётся вашим приложением, запросов к внешним сервисам нет. Заменить его можно токеном Tailwind в CSS приложения:

```css
@theme {
  --font-sans: "Your Font", sans-serif;
}
```

## Тема

По умолчанию тема следует настройке ОС и работает без JavaScript. Зафиксировать её можно на `<html>`:

```html
<html class="dark" data-theme="dark"></html>
```

Акцент, скругления и форму кнопок можно изменить в проекте. Откройте панель «Тема» в playground, настройте вид и скопируйте готовый CSS в свой файл стилей после импорта kit. Переменные акцента: `--accent`, `--accent-foreground`, `--focus`, `--link`. Форма кнопок: `--ag-button-radius`. Отступы: `--spacing` и `--ag-space-*`.

Токены определены в `src/tokens.ts`. После изменения выполните `bun run generate`: тест проверяет, что CSS совпадает с источником.
