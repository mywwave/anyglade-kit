# @anyglade/kit

## 0.4.0

### Minor Changes

- da3b62b: Новые компоненты: `Masonry` и `MasonryTile` для галереи плиток разной высоты, `SlideToConfirm` для действий, которые нельзя совершить случайным нажатием, и `SignaturePad` для подписи от руки. У `Box` появились `columns` и `breakInside` для кладки.
- da3b62b: Ссылки больше не синие по умолчанию: цвет идёт за акцентом темы, а ссылку отличает тонкая линия. Токен `text-accent` теперь монохромный, пока акцент не задан. Кольцо говорящего в `MediaTile` следует за ним.
- da3b62b: `TextSwap` двигает только изменившуюся часть текста: она уезжает вверх, новая приезжает снизу, а совпавшие начало и конец стоят. Компонент больше не дёргается при быстрой смене: анимация продолжается с текущего положения. С пропом `isShimmering` строка меняется целиком. Заголовок `FloatingPanel` меняется без анимации: смена заголовка там означает другой объект.

### Patch Changes

- da3b62b: Подсветка строки `Accordion` при наведении получила радиус и зазор от разделителя. Высота строки не изменилась.

## 0.3.0

### Minor Changes

- 020424a: Правила дизайн-системы теперь едут в пакете. При установке или через `bunx @anyglade/kit init` проект подключает их для Claude Code, Codex, Cursor и других агентов: в проект ложатся только ссылки, поэтому правила всегда совпадают с установленной версией. Ошибки линта тоже ведут к этим правилам.
